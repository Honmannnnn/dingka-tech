## 二、网络性能优化与动静分离策略

### 1. 边缘节点加速 (CDN & Edge Caching)
- **协议升级**：全站启用 **HTTP/3 (QUIC)** 与 **TLS 1.3**，将网络连接握手由 3-RTT 降低至 0-RTT/1-RTT，显著提升移动端在弱网环境下的卡牌首屏加载速度。
- **动静分流架构**：
  - **静态资源（JS/CSS/字体）**：设置 `Cache-Control: public, max-age=31536000, immutable`，文件内容 Hash 命名，直接命中边缘节点。
  - **卡牌多媒体图库**：存储于对象存储 COS，配合 CDN 边缘图片处理组件，根据客户端请求头自适应转换为 **AVIF / WebP** 格式，体积平均缩减 65% 以上。
  - **动态 SSR 页面**：启用 **Next.js 15 Partial Prerendering (PPR)**，页面的骨架屏与导航瞬间返回，动态卡牌流与库存状态流式渲染。

### 2. 压缩与传输优化
- 部署 Nginx 与 CDN 联动开启 **Brotli 压缩**（压缩率较 gzip 提升 20%~30%）。
- 字体文件使用 `next/font` 本地子集化（Subsetting），仅抽取常用 3500 个中文汉字，字库文件从 15MB 降至 800KB 以内。

## 三、大促与限量卡盒发售的高并发削峰方案

在限量稀有卡盒（如「黑焰支配者」整盒、宝可梦大师限定版）开售时，秒级瞬时流量可达常规访问的数十倍：

### 1. 流量入口防护与令牌桶限流
- Nginx 接入层配置 `limit_req_zone` 限制单 IP 每秒请求上限；
- 在 API 业务层采用 **Redis + Lua 脚本** 实现分布式令牌桶算法，瞬时超载流量平滑排队或优雅降级提示「正在排队抢购中」。

### 2. 库存防超卖（Redis 原子预扣减）
```
用户点击抢购 → Redis 执行 Lua 脚本原子扣减库存并写入用户占位标记
  ├─ 库存充足：返回成功凭证，将下单任务推入 RabbitMQ 异步队列
  └─ 库存为0：直接秒级熔断返回售罄，绝不穿透至底层数据库
```

### 3. 异步订单持久化
- 消息队列（RabbitMQ）消费者平缓消费订单请求，写入 PostgreSQL 事务并生成待支付订单，有效消除数据库写峰值风险。

## 四、高可用与系统稳定运行保障 (SRE 体系)

### 1. 自动化多环境 CI/CD 流程
- **代码提交触发**：通过 GitHub Actions 自动化执行 TypeScript 类型检查、ESLint 规范检查与单元测试。
- **镜像构建与推送**：自动打包多阶段构建 Docker 镜像，推送至私有镜像仓库。
- **滚动更新与金丝雀发布**：Kubernetes / 轻量容器集群平滑升级，新旧版本无缝切换，实现用户零感知发版。

### 2. 全方位监控与故障演练
- **服务指标监控**：Prometheus 抓取 Node.js 运行时事件循环延迟、QPS、HTTP 4xx/5xx 率，并配置 Grafana 实时大屏。
- **移动端与前端错误监控**：集成 Sentry APM，对官网和小程序首屏白屏、JS 异常、API 失败率进行秒级告警。
- **双周自动化备份**：PostgreSQL 每日全量冷备与 WAL 增量连续归档，支持 Point-In-Time 任意秒级数据恢复。
